# Integrated Xbox textured cube (experimental)

Original cube geometry with six indexed faces, two CPU-projected camera orientations with varying clip w, D32_FLOAT depth, two dynamic quadrant textures, translated RDNA2 VS/PS, 48 host draws and eight Present calls. Forward/reverse face order must produce the same interior RGB values for each view. A separate CPU barycentric, perspective-correct texture and depth reference validates the captured frames; explicitly excludes pixels within 0.75 source pixels of triangle edges, near UV discontinuities or equal-depth ties. Requires at least 13,500 compared pixels and 1,500 foreground/background pixels per frame. Not a game scene, shader-driven camera transform, lighting, blending integration, compute dispatch or performance test. Reuses the known runtime without rebuilding. Pending local execution. Run `bash experiments/xbox-scene/run.sh`.
