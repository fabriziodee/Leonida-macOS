# Synthetic Xbox draw (experimental, not yet executed)

Original synthetic RDNA2 VS/PS containers generated from the publicly documented parser layout at VIctory-macOS f5660fd. No game shaders or Xbox SDK needed. Vertex shader exports POSITION, pixel shader exports magenta. Xbox PSO stream, descriptor heap, vertex buffer, viewport, scissor, render target and DrawInstanced exercise VIctory's actual graphics path. Eight frames allow for asynchronous pipeline creation; final three must match 46,080 sampled RGB pixels and host draw count must be nonzero. Clear is black, never the expected color. The previous verified diagnostics binary is reused by SHA-256. This is an experimental source-level implementation: compiler, shader translation and GPU execution are pending. Run `bash experiments/xbox-draw/run.sh` on the original Mac environment. No game boot or gameplay claims.
