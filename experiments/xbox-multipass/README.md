# Xbox multipass render-to-texture and resource transitions (experimental)

Two offscreen render targets plus separate presentation texture. Clear first to black, second to blue, presentation to red. Draw magenta indexed quad into first; transition to COPY_SOURCE, second to COPY_DEST, copy first to second; transition second to render target, draw green indexed quad in opposite position without clearing; transition and copy second into presentation, then COMMON and PresentX. Alternate left/right positions each frame. Exact 16/16 host draws, eight successful presentations and 61,440 RGB samples across four frames required. Explicit whole-resource barriers test transitions and GPU texture copies across two draw passes; not shader texture sampling or general subresource barrier conformance. Reuse known runtime and original synthetic shaders; no game files. Pending local compile and execution. Run `bash experiments/xbox-multipass/run.sh`.
