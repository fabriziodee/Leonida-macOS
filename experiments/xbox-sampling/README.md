# Xbox pixel shader texture sampling (experimental)

Original RDNA2 pixel shader with native root tables and explicit-LOD image sample. Two RTV/SRV textures cleared with black borders and colored centers, point-clamp sampler, alternate descriptor-table binding and change texture contents. The final four captured frames must be red, green, blue, green (all 61,440 sampled RGB pixels), with 8/8 executed draws and successful presentations. This tests a constant UV at LOD0, resource/sampler descriptors and updated render-target sampling, not variable UV interpolation, filtering or mipmaps. Reuses verified runtime. No game files or SDK. Pending Mac compilation and execution; possible shader metadata/descriptor binding errors must be diagnosed from logs, not counted as passes. Run `bash experiments/xbox-sampling/run.sh`.
