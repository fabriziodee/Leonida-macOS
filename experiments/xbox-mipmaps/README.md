# Xbox mip-level render targets and SRV selection (experimental)

One 64x64 RGBA8 texture with four real mip levels (64, 32, 16, 8). Distinct RTVs clear each physical level with different colors; SRV rebasing selects a different level using the already verified constant-UV LOD0 shader. The first four frames rotate the palette, then the last four must be red, green, blue and white. Eight executed host draws and successful presentations, expected title exit 42 and 61,440 matching sampled RGB pixels required. Tests explicit mip views and render-to-mip sampling, not automatic LOD selection, generated mipmaps, trilinear/anisotropic filtering or arbitrary subresource barriers. Reuses the exact verified runtime and synthetic shader; no game assets. Pending local compilation and hardware run. Run `bash experiments/xbox-mipmaps/run.sh`.
