# Xbox depth test (experimental)

Original synthetic VS and two constant PS colors (magenta/green). D32_FLOAT depth resource, DSV, depth clear and LESS comparison. Near triangle z=0.25, far z=0.75. Frame 5 draws near then far; 6 draws far then near; both must be magenta. Frame 7 clears depth to zero, both rejected (black). Frame 8 draws green and then magenta at the same far depth, requiring LESS to reject the second (green). Exact 16/16 host draw counters, eight successful Present calls and 61,440 sampled RGB pixels across four captures required. This tests the effect of depth on color output, not direct depth readback. Reuses verified runtime, no game data or SDK. Code pending local compilation and hardware validation. Run `bash experiments/xbox-depth/run.sh`.
